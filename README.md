This is a mod for Wurm Unlimited to enable Rift event by the schedule.
The event usually starts on schedule, but you can start it with your hands. There is also an option to launch several events at the same time.

Some commands to operate with rifts:
#riftnow - random location, starting now
#riftstart - current GM location, starting now
#riftdel - delete event at GM location
#riftcretdel - to delete creatures if it's buggy
