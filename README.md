This is a mod for Wurm Unlimited to enable Rift event by the schedule

With the default settings, the rift appears on Saturday at 3 p.m. at a random location on the map. A bell rings for 3 hours, notifying the players and a red ray appears so that the players can find a place. The event is divided into 3 waves. Mobs are restricted in movement by the event area. If you take mobs outside, they teleport to the center and their health is restored. Rift mobs have their own spells: stun, freeze, summon minions, heal, and damage. After the successful completion of the event, players receive a reward with money, a rare lump of moon metals and, with some chance, various jewelry items (you must be in the event area and have a certain level of fighting). It also becomes possible to collect rift resources.

The event usually starts on schedule, but you can start it with your hands. There is also an option to launch several events at the same time.

Some commands to operate with rifts:
1. #riftnow - random location, starting now
2. #riftstart - current GM location, starting now
3. #riftdel - delete event at GM location
4. #riftcretdel - to delete creatures if it's buggy
